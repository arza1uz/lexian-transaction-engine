# ADR 0001: Use Separate Product Repositories

## Status

Accepted

## Context

The portfolio must be easy for recruiters and data leads to navigate. Each system should stand alone, while still fitting into the Lexian ecosystem.

## Decision

Use separate repositories for major Lexian products instead of a single giant monorepo.

## Consequences

- Easier navigation.
- Clearer project boundaries.
- More realistic product ownership.
- Slightly more overhead when connecting systems later.
