# Lexian Ecosystem

Lexian is a fictional fintech engineering portfolio built as a set of focused product repositories, not one giant monorepo.

Future repositories may include:

- `lexian-engineering`
- `lexian-labs`
- `lexian-transaction-engine`
- `lexian-reconciliation-engine`
- `lexian-risk-engine`
- `lexian-fraud-engine`
- `lexian-data-platform`
- `lexian-ml-platform`
- `lexian-ai-platform`

This repository is only the Transaction Engine. Future products should live in separate repositories so each system has clear ownership, a focused README, independent tests, and an understandable product boundary.

Together, these repositories should tell the story of a growing fintech data and AI engineering organization.
