# Business Context

Lexian is a fictional financial technology company focused on financial inclusion. It provides current accounts, payments, and responsible credit access to users who are underserved or rejected by traditional banking institutions.

The long-term ambition is to build systems capable of serving more than 130 million users safely and responsibly. That scale requires strong transaction integrity, fraud prevention, data responsibility, and responsible AI because many users may be financially vulnerable.

Lexian Transaction Engine is the first product in that ecosystem. It starts with a simple batch transaction flow so the core domain rules can be made explicit before more advanced infrastructure is introduced.

Lexian is a fictional fintech created for a professional engineering portfolio. This repository uses synthetic data only and does not contain real customer, employer, or production information.
