# Learning Unlocks

Lexian capabilities should be unlocked when the business need appears, not before.

## Unlock 01: CSV Batch Processing

Use synthetic CSV data to prove the transaction flow and business rules.

## Unlock 02: Validation And Data Quality

Reject missing columns, duplicate IDs, bad amounts, and unsupported transaction types.

## Unlock 03: Local Analytical Storage

Use DuckDB or SQLite when reports need queryable historical storage.

## Unlock 04: Reconciliation

Compare internal transactions against external settlement files when partner trust becomes a business need.

## Unlock 05: Postgres Warehouse

Introduce Postgres when local files are no longer enough for structured analytics.

## Unlock 06: dbt Analytics Layer

Add dbt when transformations need lineage, tests, and modular analytical models.

## Unlock 07: Orchestration

Use orchestration when workflows require scheduling, dependencies, retries, and observability.

## Unlock 08: Streaming

Add streaming when low-latency transaction updates or fraud alerts become important.

## Unlock 09: Cloud Deployment

Deploy to cloud when the portfolio needs operational realism and environment separation.

## Unlock 10: ML Pipelines

Build ML workflows when risk, fraud, or credit decisions need predictive modeling.

## Unlock 11: AI Assistants / RAG / Agents

Add AI systems when operations, support, or engineering workflows need natural-language assistance grounded in trusted data.
