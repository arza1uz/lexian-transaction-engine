# Glossary

- Transaction: A financial event that changes or records account activity.
- Deposit: A transaction that increases a user's balance.
- Withdrawal: A transaction that decreases a user's balance.
- Balance: The net amount available for a user after deposits and withdrawals.
- Reconciliation: Comparing two sources of financial truth to find mismatches.
- Risk: The possibility that a user, transaction, or product creates financial loss or compliance exposure.
- Fraud: Intentional misuse or deception involving financial systems.
- Ledger: An auditable record of financial movements.
- Batch Processing: Processing data in grouped files or scheduled runs rather than event by event.
- Data Quality: The degree to which data is accurate, complete, consistent, and usable.
- SLA: A service-level agreement that defines expected reliability or response standards.
- Pipeline: A sequence of data processing steps.
- Warehouse: A structured analytical data store used for reporting and analysis.
- Feature Store: A managed repository of ML features used for training and serving models.
- Model Serving: Running trained models so applications can request predictions.
- RAG: Retrieval-augmented generation, where an AI system answers using retrieved trusted context.
